# Source and Evidence Gate

Use this reference before drafting coursework and whenever a claim depends on external evidence.

## Source order

1. The user's direct request, preferences, and supplied facts define the task.
2. The assignment specification, rubric, and required template define assessed requirements and structure.
3. Relevant university lecture, tutorial, lab, and applied materials define the course's taught content and terminology.
4. The user's own code, data, screenshots, calculations, experiment results, and project files provide task-specific evidence.
5. External sources may be used only after the user approves web research.

These sources serve different purposes. A rubric does not prove an experimental result; a lecture example does not replace the assignment's requirements. If two authoritative sources conflict, report the conflict and ask which direction to follow when it materially affects the work.

## Inspect before asking

- Search the files and paths the user supplied, and inspect relevant workspace materials already in scope.
- Ask only for materials that are missing and relevant. Examples include the rubric, template, lecture topic, lab instructions, source code, data, run output, or a baseline measurement.
- Do not ask the user to resend something already available or demand every course file when only a subset is relevant.
- Give a short reason for each request: name the missing item and explain which claim or requirement depends on it.

## Material gap rule

A gap is material when different answers could change an important fact, calculation, method, interpretation, recommendation, conclusion, or assessed requirement.

When a material gap exists:

1. Identify the exact gap and what it affects.
2. Ask a concise, answerable question, combining related questions into one message.
3. Pause drafting the affected argument until the user responds.
4. Continue only with independent content that does not depend on the missing information, if doing so is useful and does not create a misleading partial draft.

Do not silently assume. Assumption-based drafting is allowed only after the user explicitly authorizes it. If authorized, label assumptions clearly, keep them separate from observed facts, and explain how conclusions depend on them.

## Web research permission

Do not search the web to fill gaps by default. First use the supplied assignment and university materials, then the user's own evidence. If outside information is still needed:

- explain why the course materials are insufficient;
- identify the exact fact or source needed and likely source type;
- ask the user whether web research is allowed;
- wait for approval before browsing.

If approved, prefer credible primary sources relevant to the question. Cite sources accurately and do not imply that external guidance is a course requirement unless the course material says so.

## Evidence map

For each high-impact claim, track:

| Item | Check |
|---|---|
| Claim or requirement | What exactly must be established? |
| Source | Which supplied file, output, or approved source supports it? |
| Evidence | What specific value, passage, observation, or result is relevant? |
| Status | Observed, calculated, inferred, proposed, or unknown? |
| Gap | What is not established, and does it materially affect the conclusion? |

Use this as a planning aid; include a table in the report only when it helps the intended reader.
